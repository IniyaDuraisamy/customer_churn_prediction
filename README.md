This project builds an end-to-end machine learning pipeline to predict customer churn and explain model decisions using SHAP (SHapley Additive exPlanations). It simulates a real corporate data science assignment where transparency, interpretability, and business insights are important.
1. Project Objective

The main goals of this project:

✔ Build a churn prediction model

Using XGBoost and engineered customer behavior features.

✔ Provide deep model interpretability

Using SHAP to show:

Global feature importance

Local explanations for 5 individual customers

✔ Deliver actionable business insights

Which customers are likely to churn and why.
